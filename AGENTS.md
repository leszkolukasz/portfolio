# AGENTS.md

## Language

- All created files (code, documentation, README, config) must be written in English unless the content itself requires a different language (e.g. Polish copy on a Polish-language website, i18n strings, user-facing text in a specific locale).
- Chat communication follows the language the user is currently writing in.

## Code Quality

- After making code changes, run `pnpm check` to lint and format-validate the codebase before declaring work complete. Fix any issues before handing off.
- Do not use — (em dash) as they look ugly when rendered. Use – (en dash) instead. Use hyphen (-) only in compound words like "user-facing" or "well-formed".
